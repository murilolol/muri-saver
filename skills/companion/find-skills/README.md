> Ver [`docs/skills-companion.md`](../../../docs/skills-companion.md) pra
> entender por quê.

O "gerenciador de pacotes" do ecossistema aberto de skills — descobre,
instala e atualiza skills publicadas por qualquer pessoa, direto do GitHub,
via `npx skills`.

| | |
|---|---|
| **Autor** | [Vercel Labs](https://github.com/vercel-labs/skills) |
| **Licença** | MIT |
| **Quando usar** | toda vez que sentir falta de uma capacidade específica e suspeitar que já existe uma skill pronta pra ela, antes de escrever algo do zero |
| **Vantagem de ter instalada** | sem ela, adicionar uma skill nova significa pesquisar manualmente, achar o repositório certo e copiar arquivo por arquivo. Com ela, a própria IA resolve "preciso de uma skill que faça X" e instala sozinha via `npx skills add` |

## Instalar

```bash
npx skills add vercel-labs/skills@find-skills
```
